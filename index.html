Core Principles

Minimalism

불필요한 요소를 배제하고 콘텐츠 본질에 집중할 수 있는 레이아웃을 지향합니다.

Performance

경량화된 코드로 끊김 없고 부드러운 프레임 레이트와 빠른 로딩 속도를 보장합니다.

Interactivity

사용자의 움직임에 실시간으로 반응하여 정적인 웹 페이지에 생동감을 불어넣습니다.
